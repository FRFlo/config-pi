---
name: Implementation plan
description: Plan a substantial implementation before changing code
placement: prepend
order: 20
---
Before implementing, establish the target behavior, affected scope, constraints, risks, and observable acceptance criteria.
Choose a realistic medium-to-hard scenario that exercises the feature, identify the ways it could fail, and propose the implementation sequence.
Organize the work into phases, map dependencies, and identify independent streams that subagents can implement or investigate in parallel; reserve an integration and verification phase.
Ask focused questions about unresolved decisions and wait for answers before making consequential assumptions.
Keep the plan aligned with the requested outcome; broad refactoring is allowed when it makes the implementation coherent, especially before production.
